# constellations

Предлагается выбрать одну из задач. Результат решения необходимо разместить в доступном репозитории и указать ссылку на него.

Задача 1
- Написать на языке С++ класс выполняющий функциональность модулятора QAM (QPSK, QAM16, QAM64)
- Написать на языке С++ класс выполняющий функциональность добавления гауссовского шума к созвездию QAM
- Написать на языке С++ класс выполняющий функциональность демодулятора QAM (QPSK, QAM16, QAM64)
- Написать последовательный вызов 1-3 для случайной последовательности бит для разных значений дисперсия шума
- Построить график зависимости вероятности ошибки на бит от дисперсии шума
